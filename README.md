# ks / 光る時間と、こぼれたsoup

地続きの時間が光っては、溶け、闇に沈み、浮かぶ

漫画家としての視線（ネーム）と、生成技術（アンプ）を組み合わせた、1コマの沈黙のマンガのようなフォトジェニック・ウェブジン

---

## 創作コンセプト：感性1024%

- **匿名性と漂流 (Anonymous & Drift)**
  固定された時系列や号数の枠をあえて排し、アクセスするたびに写真と言葉の配置が永久に変化し続ける「漂流する時空間」を表現する
- **疎と密 (Sparseness & Density)**
  大胆な余白、アシンメトリーな配置、ポツポツと雨のように偏在する写真によって、デジタル空間に人間らしい呼吸の痕跡を残す
- **次元の切れ目 (Dimensional Tear)**
  スクロールの途中に現れる扉をクリックすることで、別のランダムな時空へとタイムトリップ（再シャッフル）する
- **文末ルールの遵守**
  説明過多を避けるため、本ウェブジンのすべてのテキストおよび原稿は文末の句点（「。」）を完全に排除する

---

## 主な機能と実装仕様

1. **無限スクロール & クライアントサイド・シャッフル**
   ビルド時に全データを取得し、ブラウザ側で完全にランダムシャッフルして描画する　スクロールに応じて自動で次のアセットが無限にループ追加される
2. **ジェネラティブ（プロシージャル）レイアウト**
   各作品の配置（サイズ、アシンメトリーな左右寄せ、横並び、余白の強さ、縦書きテキストのバインド位置）は、シリーズIDと画像順から計算される決定論的ハッシュによって自動生成される
3. **20種類の出現アニメーション**
   各画像やテキストには、スクロール時に `reveal-blur`, `reveal-exposure`, `reveal-flicker`, `reveal-glitch` など20種類の視覚効果クラスがランダムで適用され、流動的に表示される
4. **純タイポグラフィ・レイアウト**
   写真の流れの合間に、画像を持たず言葉だけで全画面を占有する3パターン（縦書き、巨大中央寄せ、傾き）のテキストスクリーンが動的に挿入される
5. **20種類のポータル・キャプション**
   次元の切れ目（ワープボタン）には「別の路へ」「🛗」「スープがこぼれる瞬間」など20種類のキャプションがランダムで適用される
6. **時空のポケット（Indexメニュー）**
   ヘッダーの `index` から、特定の号（Volume）を選択してフィルタリングされた世界を漂流することも可能（デフォルトは全号混ざった `vol. ∞`）

## ディレクトリ構造とスケーリング（新しい号の追加方法）

本プロジェクトは画像ファイルをリポジトリ内に持たず、自前画像CDNである `86img` (`https://img.tokyo86.com/`) のURLを参照する

### 1. ディレクトリ構造
```text
src/content/
├── series/
│     ├── vol-01.json  (各号のメタデータ)
│     └── ...
└── works/
      ├── vol-01/      (各号のフォルダ)
      │     ├── 01.md  (各写真とモノローグ)
      │     └── ...
      └── ...
```

### 2. 新しい号の追加手順

#### 手順 A: シリーズ（号）の定義
`src/content/series/` の下に `vol-XX.json` を作成する

```json
{
  "title": "vol. 04 — 新たなサブタイトル",
  "description": "その号のテーマや漂う空気の説明文",
  "date": "2026-06-17",
  "order": 4
}
```

#### 手順 B: 作品ファイルの作成
`src/content/works/vol-XX/` のフォルダを作成し、その中に `01.md`, `02.md`... の順でMarkdownファイルを配置する（1号あたり15〜20枚を推奨）

```markdown
---
series: "vol-04"
imageUrl: "https://img.tokyo86.com/dnmi15/001.webp"  (86imgのCDN URL)
order: 1
monologue: "バインドする詩的な言葉（文末に。をつけない）"
---
```
※ `layout`, `spacing`, `textPosition` のフロントマター項目は、個別に固定表示したい場合のみ明示的に記述する（記述がない場合はジェネラティブエンジンにより自動でアシンメトリーな配置が割り当てられる）

## 開発コマンド

プロジェクトルートで実行する

| コマンド | 役割 |
| :--- | :--- |
| `npm install` | 依存パッケージのインストール |
| `npm run dev` | ローカル開発サーバーの起動 (`http://localhost:4321/`) |
| `npm run build` | 本番用の静的HTMLビルド（`dist/` 出力） |
| `npm run preview` | ビルドした静的ファイルのローカルプレビュー |
